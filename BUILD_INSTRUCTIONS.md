## 🐛 Решение Проблем

### Ошибка: "Dashboard2_clean not found"
**Проблема:** VSCode открыл не ту папку  
**Решение:** 
1. Закройте VSCode
2. Откройте папку `C:\Users\11218\workspace\Dashboard2`
3. Запустите компиляцию заново

### Ошибка: "CMake Error"
**Решение:**
```batch
# Удалите папку build
rmdir /s /q build

# Пересоберите
idf.py reconfigure
idf.py build
```

### Ошибка: "idf.py not found"
**Проблема:** ESP-IDF окружение не активировано  
**Решение:**
```batch
call C:\esp-idf-v5.3.3\export.bat
```
