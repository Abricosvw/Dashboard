# I2C Tools Component

Этот компонент предоставляет инструменты для работы с I2C устройствами, включая поддержку расширительного чипа CH422G для управления LCD и SD картой.

## Функции

### Базовые I2C инструменты

Компонент предоставляет консольные команды для работы с I2C:

- `i2cconfig` - Настройка I2C шины
- `i2cdetect` - Сканирование I2C устройств
- `i2cget` - Чтение регистров I2C устройств
- `i2cset` - Запись в регистры I2C устройств
- `i2cdump` - Дамп регистров I2C устройств

### CH422G GPIO Expander

CH422G - это расширитель GPIO портов на базе I2C с 8 программируемыми пинами.

#### Особенности:
- 8 GPIO пинов (0-7)
- Каждый пин может быть настроен как вход или выход
- Поддержка push-pull и open-drain режимов
- I2C адрес: 0x24 (по умолчанию)

#### Использование:

```c
// Инициализация CH422G
esp_err_t ret = ch422g_init(bus_handle, CH422G_I2C_ADDR);

// Установка направления пина (выход)
ch422g_set_direction(pin, CH422G_DIR_OUTPUT);

// Установка значения пина
ch422g_set_pin(pin, 1); // HIGH
ch422g_set_pin(pin, 0); // LOW

// Чтение значения пина (для входов)
uint8_t value;
ch422g_get_pin(pin, &value);
```

## LCD контроль через CH422G

Компонент предоставляет функции для управления LCD дисплеем через CH422G:

### Функции LCD:

- `ch422g_lcd_init()` - Инициализация LCD контрольных пинов
- `ch422g_lcd_backlight_on()` - Включить подсветку LCD
- `ch422g_lcd_backlight_off()` - Выключить подсветку LCD
- `ch422g_lcd_reset_on()` - Активировать reset LCD (низкий уровень)
- `ch422g_lcd_reset_off()` - Отпустить reset LCD

### Назначение пинов для LCD (по умолчанию):

- **Пин 0**: LCD Backlight (подсветка)
- **Пин 1**: LCD Reset

## SD карта контроль через CH422G

Компонент предоставляет функции для управления SD картой через CH422G:

### Функции SD карты:

- `ch422g_sd_init()` - Инициализация SD контрольных пинов
- `ch422g_sd_cs_on()` - Активировать Chip Select (низкий уровень)
- `ch422g_sd_cs_off()` - Деактивировать Chip Select
- `ch422g_sd_cs_set_active_low()` - Настройка полярности CS сигнала
- `ch422g_sd_cs_set_pin()` - Настройка пина для CS сигнала

### Назначение пинов для SD карты (по умолчанию):

- **Пин 2**: SD Card Chip Select (CS)

## Интеграция с SD Card Manager

CH422G может быть использован для управления CS сигналом SD карты вместо прямого GPIO управления. Это позволяет освободить GPIO пин 4 для других целей.

### Функции интеграции:

- `sd_card_use_ch422g_for_cs()` - Настройка SD card manager для использования CH422G
- `sd_card_is_using_ch422g_for_cs()` - Проверка использования CH422G

### Преимущества:

- Освобождает GPIO пин 4 для других устройств
- Централизованное управление через I2C
- Поддержка горячей замены устройств

### Настройка:

```c
// Включить поддержку CH422G в main.c
#define CONFIG_USE_CH422G_FOR_SD 1

// В app_main()
esp_err_t ret = sd_card_use_ch422g_for_cs();
if (ret == ESP_OK) {
    ESP_LOGI(TAG, "SD card now uses CH422G for CS control");
}
```

## Использование в коде

### 1. Настройка I2C шины

```bash
# В консоли ESP32
i2cconfig --port=0 --sda=18 --scl=19 --freq=100000
```

### 2. Сканирование I2C устройств

```bash
i2cdetect
```

### 3. Чтение/запись регистров

```bash
# Чтение регистра 0x00 устройства 0x24
i2cget -c 0x24 -r 0x00 -l 1

# Запись значения 0x10 в регистр 0x01 устройства 0x24
i2cset -c 0x24 -r 0x01 0x10
```

### 4. Программное управление LCD

```c
// Включить подсветку
ch422g_lcd_backlight_on();

// Выключить подсветку
ch422g_lcd_backlight_off();

// Сброс LCD
ch422g_lcd_reset_on();   // Активировать reset
vTaskDelay(pdMS_TO_TICKS(10));  // Подождать 10ms
ch422g_lcd_reset_off();  // Отпустить reset
```

### 5. Программное управление SD картой

```c
// Активировать SD карту
ch422g_sd_cs_on();

// Деактивировать SD карту
ch422g_sd_cs_off();
```

## Настройка пинов

Если вам нужно изменить назначение пинов для LCD или SD карты, отредактируйте определения в файле `ch422g.c`:

```c
// LCD Pin definitions (adjust according to your hardware)
#define CH422G_LCD_BACKLIGHT_PIN 0  // LCD backlight control pin
#define CH422G_LCD_RESET_PIN     1  // LCD reset pin

// SD Card Pin definitions (adjust according to your hardware)
#define CH422G_SD_CS_PIN 2  // SD card chip select pin
```

## Важные замечания

1. **I2C адрес CH422G**: По умолчанию 0x24. Если у вас другой адрес, измените в `ch422g_init()`
2. **Pull-up резисторы**: Убедитесь, что на линиях SDA/SCL установлены pull-up резисторы (обычно 4.7kΩ)
3. **Скорость I2C**: CH422G поддерживает до 400kHz, но по умолчанию используется 100kHz для надежности
4. **Пины**: CH422G имеет 8 пинов (0-7), которые можно использовать для других целей

## Отладка

### Проверка I2C устройств:

```bash
i2cdetect
```

Должно показать адрес CH422G (0x24) в таблице.

### Проверка регистров CH422G:

```bash
# Прочитать регистр направления (IODIR)
i2cget -c 0x24 -r 0x00 -l 1

# Прочитать регистр выходных данных (ODR)
i2cget -c 0x24 -r 0x0A -l 1

# Прочитать регистр входных данных (IDR)
i2cget -c 0x24 -r 0x0C -l 1
```

## Регистры CH422G

| Адрес | Название | Описание |
|-------|----------|----------|
| 0x00  | IODIR    | Направление I/O (0=вход, 1=выход) |
| 0x0A  | ODR      | Выходные данные |
| 0x0C  | IDR      | Входные данные |
| 0x18  | OCON     | Управление выходом (0=push-pull, 1=open-drain) |
